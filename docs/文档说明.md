# 文档说明

现场导出的表格、报告和项目说明原先混在一起，文件名里的括号、连字符和扩展名也不统一。本次只整理资料，不改导出原名，避免和来源系统对不上。

页面上的「真实资料目录」会按下面的分类显示这些文件，下载地址仍指向原文件。

## 怎么放

| 位置 | 放什么 |
| --- | --- |
| `docs/` | 给项目阅读的说明，不含现场原始表 |
| `data/true_data/` | 现场导出的原始资料，按用途分子目录 |
| `data/videos/` | 可在页面回看的视频 |
| `data/demo/` | 演示用模拟事件，不是现场记录 |
| 项目根目录 | 启动说明 `README.md`，以及页面、接口和模型代码 |

`data/true_data/` 里的六个目录：

- `环境`：传感器数值
- `事件`：视频事件统计
- `设备`：故障与人工操作
- `通信`：电话、情报板、声光报警
- `照明`：照明控制流水
- `报告`：文字运行报告

原文件名保持不动。名字里的空格、中英文括号、多余的 `xls` 都是导出时留下的，重命名会让以后核对来源变困难。

## 现场资料

统计时段以各表表头或记录时间为准。程序画曲线时只使用色尔岗曲隧道的记录。

### 环境监测 `data/true_data/环境/`

页面环境曲线直接读取这三份表。

| 文件 | 内容 | 时段与范围 | 程序是否读取 |
| --- | --- | --- | --- |
| `环境数据表 (日).xls` | 设备名称、隧道、桩号、方向、类型、数值、记录时间。同一张表里有 CO 和能见度（VI） | 日表，记录集中在 2026 年 6 月 | 是。CO、VI |
| `环境数据表 光照数据（周）.xls` | 与上表相同的列，类型为光照（LA） | 周表 | 是。LA |
| `环境数据表.风速风向xls.xls` | 与上表相同的列，类型为风速（WS）。文件名里的 `xls.xls` 是原名，不要改成单个扩展名 | 记录量最大的一张环境表 | 是。WS |

曲线保留表内原值，不做单位换算。

### 事件统计 `data/true_data/事件/`

这两份表只进入资料目录，不参与页面曲线。

| 文件 | 内容 | 时段 |
| --- | --- | --- |
| `事件类型统计表-(月).xlsx` | 事件整体统计：已处理、未处理、正报、误报和正报率 | 表头统计时间为 2026-05-01 起 |
| `分点位事件统计表-（月）.xlsx` | 按路段、任务和点位统计报警、未处置、误报、正报率，以及违停等事件类型 | 表头统计时间为 2026-06-11 起 |

两份文件名里的连字符和括号不一致，分别是 `-(月)` 和 `-（月）`，保持原样。

### 设备记录 `data/true_data/设备/`

| 文件 | 内容 | 程序是否读取 |
| --- | --- | --- |
| `故障分析记录表（月）.xls` | 设备故障码、故障时间、故障信息、是否恢复、路段、桩号、分类 | 是。页面故障表只保留路段名称为「色尔岗曲隧道」的记录 |
| `操作分析记录表（月）.xls` | 隧道、设备、操作人、执行内容和执行时间 | 否。仅供查阅和下载 |

### 通信与报警 `data/true_data/通信/`

这些文件都不进入环境曲线或故障表。

| 文件 | 内容 | 使用时注意 |
| --- | --- | --- |
| `紧急电话来电记录（月）.xlsx` | 设备、隧道、触发区域、触发类型、创建时间、桩号。工作表名为来电记录导出时间 | 标准 xlsx |
| `紧急电话数据.xls` | 扩展名是 `.xls`，文件内容实际是 xlsx（文件头为 ZIP） | 用 Excel 打开一般可以；只认扩展名的旧解析库会拒绝它。不要凭扩展名把它当成 Excel 97 格式 |
| `情报板发送记录-（历史）.xls` | 情报板发送历史，首行标题为「情报板发送记录」 | 原名带 `-（历史）` |
| `声光报警.xlsx` | 两个工作表：声光报警1、声光报警2。列为设备、盘卡器件、分区、节点、报警类型和时间 | — |

### 照明控制 `data/true_data/照明/`

| 文件 | 内容 |
| --- | --- |
| `light_ctrl_history.csv` | 照明控制流水：`id`、`device_id`、`ctrl_value`、`result`、`create_time`。体积约 37 MB，是英文列名的导出文件，没有改成中文名 |

### 运行报告 `data/true_data/报告/`

| 文件 | 内容 |
| --- | --- |
| `事件视频检测系统-运行报告（月）.docx` | 事件视频检测系统的月度运行报告，含版式和图片，不是可解析的数据表 |

## 视频与演示数据

这些不是现场导出的表格。

| 文件 | 说明 |
| --- | --- |
| `data/videos/隧道实时监控.mp4` | 本地监控视频，页面可回看 |
| `data/videos/车辆停驶故障_演示.mp4` | 按现场画面风格生成的车辆停驶短片，不是现场录像 |
| `data/videos/*.detections.json` | 播放器使用的检测结果，资料目录不列出 |
| `data/demo/simulated_events.json` | 演示用的一氧化碳升高、照度骤降、温度升高和车辆停驶。页面会标明「模拟」 |
| `data/tunnel_day_dataset.json` | 按方案生成的单日合成数据，和现场曲线分开展示 |
| `mock_data.json` | 根目录的方案演示样例 |

重新生成合成日数据：`python data/generate_synthetic_dataset.py`。重新生成车辆停驶短片：`python data/build_demo_video.py`。

## 页面实际用到的表

只有下面四份参与接口计算，路径写在 `real_data.py`：

- `data/true_data/环境/环境数据表 (日).xls`
- `data/true_data/环境/环境数据表 光照数据（周）.xls`
- `data/true_data/环境/环境数据表.风速风向xls.xls`
- `data/true_data/设备/故障分析记录表（月）.xls`

其余现场文件只供资料目录查看和下载。移动这四份文件时，要同时改 `real_data.py` 里的相对路径和 `tests/test_real_data.py` 里的检查路径。
