# 移动云 MoMA 接入信息

## 本项目已接入的能力

- 流式 Chat Completions。请求带 `stream: true`，并设置 `enable_thinking: false`，让模型直接作答，不先输出思考过程。若网关不认该字段，会自动退回不带该字段的流式请求，再退回非流式。
- 三种路由策略在应用内映射：成本优先（更短输出、更低温度）、均衡优先、效果优先（更长输出）。平台请求体只包含已确认字段。
- 异常按类型分流：照度和温度走成本优先，一氧化碳走均衡优先，车辆停驶和画面目标走效果优先。两类及以上再走均衡优先的多源关联，只复用各类短结论，不重复发送原始表和视频。某一类没有可见结论时，其余类型继续。具体模型名称以平台返回为准，应用不写入未文档化的模型参数。
- 同一会话的追问复用第一次提交的历史数据快照，避免重复发送传感器记录。
- 页面通过 `/api/v1/moma/status` 检查地址、模型 ID 和密钥是否已配置，不回传密钥本身。
