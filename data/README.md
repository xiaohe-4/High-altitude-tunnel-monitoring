# 隧道参考与演示数据

本目录同时包含现场参考资料和方案演示数据，两类数据用途不同。

## 现场参考资料

- `true_data/` 按用途分子目录保存原始文件，文件名保持导出时的原名。各文件用途、统计时段和程序是否读取，见项目根目录 `docs/文档说明.md`。
- `true_data/环境/`：一氧化碳、能见度、光照、风速风向。
- `true_data/事件/`：事件类型与分点位统计。
- `true_data/设备/`：故障分析与操作分析。
- `true_data/通信/`：紧急电话、情报板、声光报警。
- `true_data/照明/`：照明控制历史。
- `true_data/报告/`：事件视频检测系统运行报告。
- `videos/` 保存本地视频文件，仪表盘提供浏览器内回看。其中 `车辆停驶故障_演示.mp4` 是生成的模拟故障短片。
- `demo/simulated_events.json` 是演示用的一氧化碳、照度、温度和车辆停驶事件，不写入现场工作簿。
- 页面曲线只读取色尔岗曲隧道的环境表与故障分析表；其余原始文件可从页面资料目录下载。
- 这些文件是历史参考数据，不代表当前实时状态。

## 合成演示数据

`tunnel_day_dataset.json` 是按方案生成的单日合成环境与事件样例，前端将它与真实资料分区展示，避免混淆。

## 生成命令

```bash
python data/generate_synthetic_dataset.py
```

## 合成数据产出文件

- `tunnel_day_dataset.json`：完整单日数据集

## 关键字段

- `tunnel`：隧道基础信息
- `camera_points`：监测点位配置
- `sensor_series`：5 分钟采样的环境数据
- `events`：事件列表（停车、设备故障、CO异常等）
- `video_manifest`：演示视频清单
- `risk_summary`：总风险概况

数据来源与历史时间说明见上方“现场参考资料”。
